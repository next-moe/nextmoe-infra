# Declared breaking changes for docs/chat/openapi.yaml.
#
# oasdiff --err-ignore matches by SUBSTRING: an entry suppresses a breaking
# change when the entry line CONTAINS oasdiff's own error text verbatim
# ("in API <METHOD> <path> <description>"). Lines that match nothing -- this
# header included -- are inert. Removing an entry re-arms the gate for that change.
#
# 2026-09-28, the document learns the wire. Nothing the server sends changed.
#
# - Seven pointer-to-struct fields (media, reply_to, reply_quote, service_action,
#   context, draft, last_message) were published as a bare, required $ref while
#   the server sends null for them. They are now anyOf [$ref, {type: null}];
#   oasdiff reads that wrapper as a type change plus the removal of every nested
#   required property.
# - Error responses referenced huma's ErrorModel (instance: format uri) while the
#   server sends problem.Problem, whose instance is the request path. They now
#   reference Problem.
#
# The generated Dart client of kungal-apps could not parse a message without
# media against the old document. These entries cover this one transition only;
# the next change to the chat document deletes them.
