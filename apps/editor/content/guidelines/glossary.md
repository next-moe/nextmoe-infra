按主题分组。遇到不熟悉的词，先在这里查，再顺着链接读详细说明。

## 条目类型 {#entities}

| 术语   | 说明                                                                                                                     |
| ------ | ------------------------------------------------------------------------------------------------------------------------ |
| 条目   | 资料库里的一个对象：一部作品、一个角色、一个厂商……每个条目有唯一编号。                                                   |
| 作品   | 一部游戏（或其他媒介的作品）本身，与具体哪个版本无关。见[作品基础信息与分级](/guidelines/work-basics)。                  |
| 发行   | 作品的一个具体版本：平台、语言、发售日、普通版/限定版/体验版等。一部作品可以有很多发行。见[发行](/guidelines/releases)。 |
| 角色   | 作品里登场的虚构人物。同一角色在多部作品里出现时，可以用「实例归属」连到主条目。见[角色](/guidelines/characters)。       |
| 人物   | 现实中的一个人（画师、作家、声优……）。见[署名名与人物](/guidelines/credit-names-and-persons)。                           |
| 署名名 | 制作人员表或配音表上**印出来的那个名字**。一个人物可以有多个署名名（笔名、旧名）。制作人员表挂的是署名名，不是人物。     |
| 厂商   | 品牌、社团、发行商、出版社、文库等。见[厂商条目](/guidelines/companies)。                                                |
| 系列   | 若干作品组成的系列。见[关联作品与系列](/guidelines/relations-and-series)。                                               |
| 引擎   | 作品使用的游戏引擎。                                                                                                     |
| 词表   | 标签和特质这两套共享的分类词汇。见[标签与特质词表](/guidelines/tags-and-traits)。                                        |
| 标签   | 描述作品内容的词，例如「校园」「时间循环」。                                                                             |
| 特质   | 描述角色的词，例如「黑发」「傲娇」。                                                                                     |

## 编辑流程 {#workflow}

| 术语                 | 说明                                                                                                                                       |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| 提案                 | 针对一个条目提交的一组修改，等待审核或直接生效。见[提案、审核与回滚](/guidelines/proposals-and-review)。                                   |
| 直接生效             | 你本人有权合并这次修改，提交的同时就写入资料库，不进入审核队列。                                                                           |
| 修订                 | 提案生效后在条目上留下的一个版本记录。条目的修订历史可以对比、回滚。                                                                       |
| 基准版本             | 你开始编辑时条目所处的版本。合并时用它判断有没有冲突。                                                                                     |
| 冲突                 | 提案提交后，条目上同一个字段又被别的修订改过。审核者必须明确选择修正或拒绝这个字段。见[冲突](/guidelines/proposals-and-review#conflicts)。 |
| 审核                 | 有审核权的人对提案逐字段采纳、修正或拒绝，然后合并或拒绝整条提案。                                                                         |
| 修正                 | 审核者把某个字段改成自己确认后的值再合并。原始提议仍留在记录里。                                                                           |
| 回滚                 | 把条目恢复到某个版本，或撤销某一版的修改。回滚本身也是一条修订。                                                                           |
| 导入原始状态（基线） | 条目第一次被人工编辑前的样子，回滚的最后一道底。                                                                                           |
| 草稿                 | 保存在你本机浏览器里的未提交修改。                                                                                                         |
| 修改说明             | 提交时写的说明：改了什么、依据是什么。                                                                                                     |

## 数据来源 {#data}

| 术语              | 说明                                                                                                                      |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------- |
| 资料源            | 导入数据的外部来源：VNDB、Bangumi、ErogameScape（批评空间）、DLsite、Getchu、Steam、HowLongToBeat 等。                    |
| 资料源行          | 由导入任务写入的列表行，标着来源名。不能删除，只能隐藏。见[资料源数据与人工编辑](/guidelines/upstream-data)。             |
| 人工行 / 人工车道 | 人在编辑台添加的列表行，标「人工」，导入任务不会修改或删除它。                                                            |
| 人工维护          | 字段的当前值是人写的。之后导入任务不会再覆盖它，包括被人清空的值。                                                        |
| 隐藏              | 让一条资料源行不再显示，资料源再次同步也不会加回；可以随时恢复。                                                          |
| 身份链接          | 表明「这个条目就是某资料站上的那个条目」的外链。不能隐藏；认错了要走合并请求或修改署名归属。见[外链](/guidelines/links)。 |
| 机翻              | 机器翻译生成的文本，只在没有原文时显示；改写后变为人工维护。                                                              |

## 权限与额度 {#permissions}

| 术语     | 说明                                                                                                                |
| -------- | ------------------------------------------------------------------------------------------------------------------- |
| 审核者   | 能审核提案的人：moderator、admin、ren，以及各站点的站点版主等。见[角色、权限与配额](/guidelines/roles-and-quotas)。 |
| 编辑者   | 通过申请获得的角色：作品与发行的修改直接生效（有每日免审额度），不能审核别人。                                      |
| 作品主人 | 认领并建立某部作品的账号，对这部作品及其发行有审核权。                                                              |
| 共享条目 | 角色、人物、署名名、厂商、标签、特质、系列、引擎。它们被许多作品引用，任何人的修改都要另一人审核。                  |
| 档位     | 计算额度的分组：普通档、编辑者档、审核档。                                                                          |
| 滑动窗口 | 额度的统计方式：每次提交在 24 小时（默认）后单独退出统计，而不是每天零点清零。                                      |

## 新建与合并 {#create-merge}

| 术语     | 说明                                                                                                                                           |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| 认领     | 新建作品的方式：填写基本信息和资料站链接；链接已对应到某部作品时，直接认领那部作品。见[新建条目与合并重复条目](/guidelines/create-and-merge)。 |
| 疑似重复 | 新建时系统发现同名条目给出的提示，需要逐个核对后再决定。                                                                                       |
| 合并请求 | 请审核者把两个重复条目合并成一个。                                                                                                             |
| 冷静期   | 合并请求批准后到真正执行之间的等待时间（默认 48 小时），留给大家发现问题。                                                                     |
| 重定向   | 被合并掉的条目的旧链接会自动跳转到保留的条目。                                                                                                 |

## 剧透与分级 {#spoilers-ratings}

| 术语     | 说明                                                                                                                    |
| -------- | ----------------------------------------------------------------------------------------------------------------------- |
| 剧透等级 | 无剧透 / 轻微剧透 / 严重剧透，用于标签、登场角色、角色特质、制作人员等。见[标签与剧透](/guidelines/tags-and-spoilers)。 |
| 内容分级 | 作品整体的全年龄 / 敏感 / R18。见[作品基础信息与分级](/guidelines/work-basics)。                                        |
| 图片分级 | 每张封面、截图的「性暗示」（安全 / 擦边 / 露骨）与「暴力」（无 / 暴力 / 血腥）。见[封面与截图](/guidelines/media)。     |
