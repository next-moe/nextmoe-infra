**攻略**记录的是一部作品的**选项图**：从哪里开始，选哪些选项，在哪里存档，最后走到哪个结局。它不是一篇文章，不写心得和剧情介绍，只写玩家照着走就能到达结局的那条路。

在作品编辑页的「攻略」分区里可以看到这部作品的全部攻略，「新建攻略」会在新标签页打开编辑器。

> [!IMPORTANT]
> **不要照抄别的攻略站的文字。** 选项本身是游戏里的原文，可以照录；攻略站作者写的说明、心得、提示属于他们的作品，不要搬进来。

## 基本概念 {#concepts}

| 概念       | 含义                                                                                       |
| ---------- | ------------------------------------------------------------------------------------------ |
| **入口**   | 开始游戏的地方，通常是 START；通关某个结局后才出现的新起点也是入口                         |
| **存档**   | 一个存档点。在路线段里加一个「存档」步骤就会在那里建立它，之后的路线可以从它出发           |
| **结局**   | 路线的终点，有个人线、后宫、真结局、普通、坏结局、后日谈等类型                             |
| **路线段** | 从一个入口、存档或结局出发，经过若干选项，走到下一个结局（或回收后结束、未完待续）的一段路 |
| **分节**   | 把路线段分组，通常一条角色线一节                                                           |

一段路的起点可以是**结局**：这表示通关这个结局之后接着玩的 AFTER 部分。

## 按角色拆分 {#by-character}

攻略页按角色展示路线，所以要告诉资料库每段路属于谁：

- 把**结局**归属到角色上。个人线结局归属一个角色，后宫结局可以归属多个。
- 把**分节**归属到角色上。分节里没有走到个人结局的路线段，也会按分节的角色着色。
- 两者都没有归属的路线段会显示在「共通 / 其他」里。

角色要**关联角色库**：在左栏展开角色，从作品的角色表里选择对应的角色。关联之后，攻略页会显示这个角色的立绘和中文名。角色表里找不到的角色可以先不关联，左栏会标出「未关联」。

## 从文字生成草稿 {#from-text}

已经写好文字攻略时，点大纲上方的「从文字生成」，把文字粘贴进去，模型会把它整理成选项图草稿。载入后对照原文检查一遍再提交。草稿可能漏掉选项，结果里会列出可能漏掉的行。

只粘贴你自己写的内容，不要粘贴其他攻略站的原文。每人每天最多生成 20 次，粘贴的文字不会被保存。

## 语言与译文 {#language}

- **日文原文**：选项照游戏里的原文写，每一步下面可以附上中文译文。导入的攻略都是这种，译文是机器翻译的，可以直接改写。
- **简体中文**：直接用中文写选项，不需要译文。从日文切换到中文时，现有的译文会被清除（可以撤销）。

人名没有可靠的中文译名时，译文里保留原文写法，不要自己音译。

### 适用版本与译者署名 {#release}

官方中文版、汉化补丁的选项文字往往和原版不同。照着某个版本写攻略时，在左栏「适用版本」里选择对应的发行，汉化组等署名会从这个发行上带出来。还没有对应的发行时，先在作品的「发行」分区里新建，再回来选择。同一部作品可以有多篇攻略，分别对应原版和各个译本。

## 游戏自带路线提示 {#route-hints}

有些游戏自己就能打开路线或选项提示（例如 2024 年的 ToHeart 重制版）。这时在作品编辑页「基础」分区打开「游戏自带路线提示」，攻略页会先提醒读者可以使用游戏自带的提示，读者确认后才展开攻略。

## 编辑器的键盘操作 {#keyboard}

大部分操作在步骤的输入框里就能完成：

| 按键                | 作用                      |
| ------------------- | ------------------------- |
| Enter               | 在下方新建一步            |
| Backspace（空步骤） | 删除这一步                |
| ↑ / ↓               | 移到上一个 / 下一个输入框 |
| Alt + ↑ / ↓         | 调整这一步的顺序          |
| Ctrl/⌘ + D          | 复制这一步                |
| Alt + A             | 切换 ☆ 标记               |
| Ctrl/⌘ + Z          | 撤销                      |
| Ctrl/⌘ + S          | 提交                      |
| ?                   | 显示全部快捷键            |

步骤和路线段都可以拖动排序，步骤也可以拖到另一条路线段里。

## 提交与审核 {#review}

攻略的修改和作品一样走[提案与审核](/guidelines/proposals-and-review)：受信编辑者的修改直接生效，其他人的修改进入审核队列。顶栏的问题计数没有清零之前不能提交，点开它可以逐条跳到需要修正的地方。

被人工改过的攻略，导入流程不会再覆盖它。挂错作品的攻略可以在提案里改所属作品；内容不适合展示的攻略可以在左栏隐藏。
