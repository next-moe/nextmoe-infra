**发行**是一部作品的一个具体版本：PC 初回限定版、下载版、家用机移植版、官方中文版、体验版、汉化补丁……它们都属于同一部作品，只是发售形式、语言、平台、日期不同。

在作品编辑页的「发行」分区里，左侧按版本类型分组列出这部作品的所有发行，选中一个后右侧可以直接编辑它。

> [!IMPORTANT]
> **同一部作品的不同版本要记成发行，而不是新建一部作品。** 只有内容上确实是另一部作品（重制、续作、FD 等）时，才作为独立作品并用 [关联作品](/guidelines/relations-and-series) 连接。

## 版本类型 {#release-kinds}

| 类型       | 含义                              |
| ---------- | --------------------------------- |
| **正式版** | 默认的、未特别区分的发行          |
| **数字版** | 下载版、数字发行                  |
| **实体版** | 实体包装、光盘、卡带              |
| **体验版** | 体验版、试玩版                    |
| **补丁**   | 补丁，包括非官方的汉化 / 翻译补丁 |

## 各项信息 {#release-fields}

| 项目         | 填法                                                                                                                    |
| ------------ | ----------------------------------------------------------------------------------------------------------------------- |
| **标题**     | 这个版本自己的名称（如「初回限定版」「HD Edition」「官方中文版」的完整标题）；和作品标题完全一样时可以留空。最多 300 字 |
| **语言**     | 这个发行的主要语言                                                                                                      |
| **支持语言** | 这个版本支持的**全部**语言（界面 / 文本语言）                                                                           |
| **支持平台** | 这个版本对应的全部平台，第一个视为主要平台                                                                              |
| **发售日期** | 见下文                                                                                                                  |
| **引擎**     | 这个版本使用的引擎（与原版不同时尤其要填）                                                                              |
| **免费发行** | 是否免费发布；查不到时选「未知」，不要猜                                                                                |
| **官方发行** | 是否为官方发行；非官方汉化补丁等填「否」；查不到时选「未知」                                                            |
| **年龄限制** | 见下文                                                                                                                  |

### 发售日期 {#release-date}

日期分年、月、日三部分，**只知道年份或年月时只填前面几项**，不要用 1 月 1 日、1 日之类的值去补齐：

|     | 已知信息               | 填写                             |
| --- | ---------------------- | -------------------------------- |
| ✅  | 2018 年 6 月 29 日     | 2018 / 6 / 29                    |
| ✅  | 只知道「2019 年冬」    | 2019                             |
| ✅  | 只知道「2020 年 3 月」 | 2020 / 3                         |
| ❌  | 只知道 2019 年         | 2019 / 1 / 1（会被当成确切日期） |

年份范围 1950–2200；填了日就必须填月。未发售但已定档的作品可以填预定日期，发售后请核对是否延期。

### 年龄限制 {#minage}

填官方标注的年龄限制数字：全年龄填 0，12 禁、15 禁、17 禁、18 禁分别填 12、15、17、18。范围 0–18，不知道时留空。

- 同一作品的 18 禁原版和全年龄移植版是两个发行，各自填自己的年龄限制。
- 作品整体的分级在作品「基础」里填，见 [分级](/guidelines/work-basics#content-rating)。

### 平台与语言 {#release-platforms}

- 平台只能从固定列表选择；一个发行同时支持多个平台时全部加上，把最主要的放在第一个。
- 支持语言写这个版本**实际支持**的语言：日文原版写日语；官方中文版写简体中文（或繁体中文）以及它保留的其他语言。
- 非官方汉化补丁：版本类型选「补丁」，官方发行填「否」，支持语言写汉化后的语言。

## 发行层面的厂商 {#release-companies}

「开发与发行商」记录只对这个版本成立的厂商身份（开发 / 发行 / 品牌 / 社团），例如：

- 官方中文版的发行商或代理商；
- 家用机移植版的移植开发商；
- 某个地区的发行商。

对整部作品都成立的身份记在作品上，见 [厂商、引擎与平台](/guidelines/companies-engines-platforms#work-or-release)。每个发行最多 50 条；资料源导入的厂商身份不能修改，不对时隐藏它再添加正确的。

## 隐藏发行 {#hide-release}

「隐藏这个发行」会让这个发行不再出现在任何页面上，可以随时恢复。适用于：

- 根本不存在的版本、重复记录的同一个版本；
- 与这部作品无关、被错误挂到这里的发行。

已取消的版本、信息不全的版本**不要隐藏**——补全信息即可。发行挂错了作品时，请在修改说明里写明正确的作品，由审核者处理。

## 新建发行 {#create-release}

在作品编辑页的「发行」分区点「新建发行」，会在新标签页打开新建页面，并自动关联到当前作品；新建完成后回到编辑页点「刷新」即可看到它。新建前先在列表里确认这个版本还没有被记录过。新建的规则见 [新建条目与合并重复条目](/guidelines/create-and-merge)。

## 常见错误 {#common-mistakes}

- **把移植版、中文版新建成另一部作品**：它们是发行。
- **用 1 月 1 日补齐不完整的日期**：只填已知的部分。
- **把作品分级填进年龄限制，或反过来**：年龄限制是这个版本的官方标注数字。
- **把中文代理商记在作品上**：记在中文版发行上。
- **隐藏信息不全的发行**：请补全，而不是隐藏。
- **非官方补丁标成官方发行**：汉化补丁的「官方发行」应为「否」。

## 字段对照 {#field-reference}

| 界面名称            | 字段                                                    | 说明                                     |
| ------------------- | ------------------------------------------------------- | ---------------------------------------- |
| 版本类型            | `catalog.release.kind`                                  | 正式版 / 数字版 / 实体版 / 体验版 / 补丁 |
| 标题                | `catalog.release.title`                                 | 可空，最多 300 字                        |
| 语言                | `catalog.release.lang`                                  | 单个语言，可空                           |
| 支持语言            | `catalog.release.languages`                             | 语言列表                                 |
| 支持平台            | `catalog.release.platforms`                             | 平台列表，第一个为主要平台               |
| 发售日期            | `catalog.release.released`                              | 年（必填）/ 月 / 日                      |
| 引擎                | `catalog.release.engine_id`                             | 可空                                     |
| 免费发行 / 官方发行 | `catalog.release.freeware` / `catalog.release.official` | 是 / 否 / 未知                           |
| 年龄限制            | `catalog.release.minage`                                | 0–18，可空                               |
| 开发与发行商        | `catalog.release.labels`                                | 厂商 + 身份，最多 50 条                  |
| 隐藏这个发行        | `catalog.release.hidden`                                | 隐藏后可恢复                             |
