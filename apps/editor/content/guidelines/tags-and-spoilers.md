标签描述作品**包含什么**：题材、舞台、人物设定、玩法、系统特征等。读者用标签筛选作品、屏蔽不想看的内容，所以标签要**准确**，剧透等级要**标对**。

标签词表本身（名称、上下级、是否色情相关）的维护见 [标签与特质词表](/guidelines/tags-and-traits)；本篇只讲「给一部作品打标签」。

## 一张表里的全部标签 {#tag-table}

「标签」分区把这部作品的所有标签合并成一张表，每行一个标签，同一个标签来自多个资料源时只占一行：

- **来源**：这个标签来自哪里——「人工」是编辑者添加的；VNDB、Bangumi 等是资料源导入的，后面的「×数字」是资料源上标记这个标签的人数，可作为参考。
- **剧透等级**：行内直接选择，见下文。
- **分类标签页**：全部 / 内容 / 色情相关 / 元信息 / 未映射 / 人工添加 / 已隐藏。「未映射」是资料源上的标签名还没有对应到词表里的标签，只能查看。

## 添加、移除与隐藏 {#add-remove-hide}

| 操作         | 适用于           | 效果                                                                     |
| ------------ | ---------------- | ------------------------------------------------------------------------ |
| **添加标签** | 任何词表里的标签 | 作为人工标签加到作品上                                                   |
| **移除**     | 人工添加的标签   | 从作品上去掉                                                             |
| **隐藏**     | 资料源导入的标签 | 这个标签在这部作品上**所有来源**的记录都不再显示，资料源再同步也不会加回 |
| **恢复**     | 已隐藏的标签     | 取消隐藏                                                                 |

> [!IMPORTANT]
> 隐藏是针对「这个标签 + 这部作品」的：一旦隐藏，VNDB、Bangumi 等所有来源的这个标签都会从这部作品上消失。只有当标签**确实不符合**这部作品时才隐藏；仅仅因为资料源上的标记人数少，不是隐藏的理由。

## 打标签的原则 {#tagging-principles}

- **只标作品里确实存在、且有一定分量的内容。** 一闪而过的情节、只在某个隐藏结局出现的元素，要么不标，要么标上相应的剧透等级。
- **标最贴切的那一级。** 标签有上下级关系（例如「发色」之下有具体颜色），给作品打最具体、最准确的那个即可，不必把上级标签也一并打上。
- **客观描述，不做评价。** 标签不是「好玩」「神作」「我推」的地方。
- **色情相关的标签照实标注。** 这类标签决定作品对设置了屏蔽的读者是否可见，漏标会让不想看到的读者看到，标错则会误伤。

## 剧透等级 {#spoiler-levels}

剧透等级回答的问题是：**一个还没玩过的人，看到这个标签会不会被提前揭露不想知道的内容？** 有三档：

| 等级         | 判断标准                                                                                 | 例子                                                     |
| ------------ | ---------------------------------------------------------------------------------------- | -------------------------------------------------------- |
| **无剧透**   | 官方简介、宣传、游戏开头就能知道的信息                                                   | 「夏天」「离岛」「校园」「女性主角」                     |
| **轻微剧透** | 游戏中期才揭示、或只在部分路线出现的设定与发展，知道了会削弱一部分体验，但不涉及核心真相 | 某条路线才出现的情节元素、中途才揭示的角色背景           |
| **严重剧透** | 结局、核心真相、反转、角色的真实身份、死亡等关键剧情                                     | 「时间循环」作为后期反转的核心机制、「唯一真结局」的内容 |

> [!TIP]
> 拿不准时按**更高**的等级标。标高了，最多是一部分读者要多点一下才能看到；标低了，就是真的剧透了别人。

同一个标签在不同作品上的剧透等级可以不同：「时间循环」在一部开场即点明循环的作品里是无剧透，在一部以循环为最终反转的作品里是严重剧透。

**剧透等级对这个标签在这部作品上的所有来源同时生效**：你为某个标签设置等级后，VNDB、Bangumi 导入的同一个标签都会使用这个等级，资料源再同步也不会覆盖。只能为这部作品上已有的标签设置剧透等级；要给新标签设等级，先添加这个标签。

## 常见错误 {#common-mistakes}

- **剧透等级标低**：拿不准时宁高勿低。
- **因为不喜欢某个标签就隐藏**：隐藏会去掉所有来源的这个标签，只在标签确实不符合作品时使用。
- **上下级标签一起打**：打最具体的那一个即可。
- **把评价当标签**：标签只描述内容。
- **漏标色情相关标签**：会让开启了屏蔽的读者看到不想看的内容。
- **用标签记录角色的个人设定**：角色的发色、性格等属于角色的特质（见 [角色](/guidelines/characters)），不是作品标签。
