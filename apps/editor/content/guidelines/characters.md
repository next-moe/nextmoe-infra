## 两层信息：角色本身 vs. 角色在本作中 {#two-layers}

一个角色条目可能出现在多部作品里（续作、FD、外传）。所以编辑角色时要分清两层：

| 层次 | 在哪里改 | 例子 |
|---|---|---|
| **角色在本作中** | 作品工作区「角色」分区，右栏上半部分「在本作中」 | 在这部作品里是主要角色还是登场角色、这个角色的存在本身是否剧透 |
| **角色本身** | 同一个右栏下半部分的标签页，或角色自己的编辑页 | 名字、生日、身体数据、简介、特质、立绘 |

改「角色本身」会影响这个角色出现的**所有作品**，改「在本作中」只影响当前作品。

> [!NOTE]
> 角色是多部作品共用的条目。**所有人的修改（包括审核者自己的修改）都要经过另一位审核者确认**才会生效，不会像作品那样直接生效。

## 角色在本作中 {#in-this-work}

### 出场程度 {#roster-role}

| 出场程度 | 用于 |
|---|---|
| 主要角色 | 主角、可攻略角色、贯穿主线的核心人物 |
| 次要角色 | 有固定戏份、有名有姓的配角 |
| 登场 | 只是出场、客串或路人性质的角色 |
| 未分类 | 资料源没有给出出场程度；你确认后请改成具体的一项 |

### 剧透等级 {#roster-spoiler}

如果「这个角色出现在本作里」这件事本身就是剧透（例如后期才揭晓的隐藏角色、真结局才登场的人物），把剧透等级设为「轻微剧透」或「严重剧透」。拿不准就选更高的一级。

### 添加、移除与隐藏 {#add-remove-hide}

- **添加角色**：在角色列表右上角「添加角色」搜索已有角色；角色条目还不存在时点「新建角色」，在新标签页建好后再回来添加。
- **人工添加的角色**可以直接移除。
- **资料源导入的角色**不能删除，只能「在本作中隐藏」：它确实不属于这部作品时才这样做（例如同名角色被对错了作品）。隐藏后以后的同步也不会让它重新出现，随时可以恢复。
- 已被隐藏的角色不能直接再添加回来，要先「恢复」。

## 角色本身 {#the-character}

### 名字 {#names}

| 字段 | 填什么 |
|---|---|
| 显示名 | 角色在原作里的名字原文，例如「鳴瀬しろは」 |
| 罗马字 | 名字的罗马字（可选）。官方有写法就用官方写法 |
| 名字的语言 | 显示名本身的语言，通常与作品的原语言一致 |

不要在显示名里加注释或译名（例如「鳴瀬しろは（白羽）」）。中文名、昵称写在「别名」里。

### 别名 {#aliases}

别名用来记录同一个角色的其他叫法，方便搜索。每条别名有名称、语言、类型，可选罗马字：

- **译名**：官方或通行的中文名、英文名等，例如「鸣濑白羽」；
- **异写**：同一个名字的其他写法（全半角、旧字体、加不加空格）。

「该语言主名」表示这条是该语言下首选显示的名字（例如该角色最通行的中文名）。资料源导入的别名可以单独隐藏；已经由资料源提供的别名不要再手动添加一遍，系统会拒绝并提示改用隐藏。

### 基础资料与身体数据 {#basic-and-body}

| 字段 | 规则 |
|---|---|
| 性别 | 男 / 女 / 其他；不知道就留空。留空表示「没有记录」，和「其他」不同 |
| 血型 | A / B / AB / O，官方没写就留空 |
| 生日（月）/（日） | 官方设定才填，可以只填月份 |
| 身高、体重 | 单位分别是厘米、千克，只填整数 |
| 胸围、腰围、臀围 | 单位厘米，只填整数 |
| 罩杯 | 官方设定的写法，例如「C」 |

> [!IMPORTANT]
> 只填**官方公开的设定**（官网角色介绍、设定集、游戏内资料）。不要根据立绘估算身高或罩杯，也不要填同人设定。

### 简介 {#intros}

角色简介和作品简介一样，**每种语言一段**，人工写的简介优先于资料源导入的版本显示。写法要求：

- 介绍角色的身份、性格和与主角的关系，用自己的话概括；
- **不要写剧透**：结局、身世真相、隐藏设定都不要放进简介；
- 转载官方角色介绍时，在修改说明里注明出处。

分区里还有一个「描述」字段，那是资料源带来的原始说明文字，公开的角色页面展示的是「简介」。补充或重写角色介绍，请写在简介里。

### 特质 {#traits}

特质描述角色的外貌、性格、身份、经历等，例如「白发」「天然呆」「青梅竹马」。每条特质有两个附加设置：

- **剧透等级**：这条特质是否剧透。比如「其实是幽灵」应该是严重剧透。
- **是谎言**：角色对外宣称、但实际上不成立的设定。例如角色自称是大小姐其实不是，可以加「大小姐」并勾选「是谎言」。

规则：

- 只能选**可以直接标注**的特质；「发色」「性格」这类分组标题本身不能加到角色上，要选它下面的具体特质（如「白发」）。
- 资料源导入的特质可以单独隐藏；如果只是剧透等级或「是谎言」不对，给这条特质添加一条人工记录并改正设置即可，人工记录会接管它。
- 同一条特质不能既被隐藏又被人工添加：要重新启用一条已隐藏的特质，先在一次单独的修改里取消隐藏。
- 特质的含义见[标签与特质词表](/guidelines/tags-and-traits)。

### 立绘 {#images}

| 字段 | 放什么 |
|---|---|
| 立绘 | 角色的官方立绘或头像，用于列表与角色页 |
| 去背景立绘 | 背景透明的全身立绘。系统会自动从立绘里抠图生成；你手动替换后，自动抠图的依据会被清除 |

只用官方图片，不要用同人图、截图拼接或加了水印的图。性暗示和露骨的图片不要设为立绘。

### 实例归属 {#instance-of}

同一个角色在另一部作品里有一份独立的条目（例如续作里年龄、身份都变了的同一人），可以把那份条目的「实例归属」指向**主条目**：

- 只能指向一层：被指向的主条目自己不能再是别人的实例；
- 一个已经是别人主条目的角色，不能再变成实例；
- 不能指向自己。

只有确认「是同一个人物设定」时才使用；同名、同声优但不是同一个角色的，不要用实例归属关联。

## 常见错误 {#common-mistakes}

| ❌ 错误做法 | ✅ 正确做法 | 原因 |
|---|---|---|
| 想把角色从本作移走，却去改角色本身的资料 | 在「在本作中」里隐藏或移除 | 角色本身会影响它出现的所有作品 |
| 显示名写「鳴瀬しろは（白羽）」 | 显示名写原文，中文名加为译名别名 | 显示名只放原作名字 |
| 根据立绘估算身高、罩杯 | 只填官方设定 | 资料库只记录可查证的信息 |
| 简介里写「真结局中她其实……」 | 剧透内容不写进简介；必要时用带剧透等级的特质 | 简介对所有人可见，没有剧透开关 |
| 把「发色」这种分组标题加到角色上 | 选具体的「白发」「黑发」 | 分组标题不能直接标注 |
| 把同名的两个角色用实例归属连起来 | 只连接确认是同一角色设定的条目 | 实例归属表示「同一个人物」 |
| 性别不知道时选「其他」 | 留空 | 「其他」是一个明确的设定值 |
