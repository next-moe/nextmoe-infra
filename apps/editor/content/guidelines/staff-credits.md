先读[署名名与人物](/guidelines/credit-names-and-persons)：本篇默认你已经知道「署名名」是职员表上印的名字、「人物」是名字背后的人。

## 一条署名记录由什么组成 {#anatomy}

作品的每一条制作人员记录（下文称「署名」）回答的是：**这部作品里，谁以什么名字担任了什么职位**。

| 部分     | 必填     | 说明                                                             |
| -------- | -------- | ---------------------------------------------------------------- |
| 职位     | 是       | 原画、剧本、音乐、声优……从职位列表里选                           |
| 署名名   | 是       | 职员表上印的名字。找不到就先新建署名名                           |
| 配音角色 | 声优必填 | 这位声优在本作里配的是哪个角色                                   |
| 备注     | 否       | 简短补充，例如「部分配音」「追加剧本」，最多 500 字              |
| 剧透等级 | 否       | 这条署名本身是否剧透（例如隐藏角色的声优），默认无剧透           |
| 仅限发行 | 否       | 这条署名只适用于本作的某一个发行版本，例如只在移植版里新增的声优 |
| 所属厂商 | 否       | 这位制作人员以哪家公司的身份参与，例如外包的音乐公司             |

**职位 + 署名名 + 配音角色**三者共同确定一条署名：同一部作品里，这三项完全相同的署名只能有一条。

- 同一个人在本作担任两个职位（例如原画兼人物设定），就是两条署名。
- 同一位声优配了两个角色，也是两条署名，各自选不同的配音角色。
- 「仅限发行」必须是**本作自己的**发行版本，选了别的作品的发行会被拒绝。

> [!TIP]
> 一部作品最多可以有 500 条人工添加的署名，正常作品远远用不到。署名数量多的时候，用列表顶部的筛选框按名字、职位或角色找。

## 职位怎么选 {#roles}

职位列表很长（动画、游戏、音乐的职位都在里面），选的时候注意：

- **按职员表原文对应**：职员表写「原画」就选「原画」，写「シナリオ」选「脚本」或「剧本」，写「キャラクターデザイン」选「人物设定」。
- 列表里有个别**同名职位**（例如「原画」「脚本」各有不止一个）。选和这部作品里已有的同类署名相同的那一个，保持一致。
- 实在找不到对应职位时选「其他」，并把职员表原文写在备注里。
- 「声优」是唯一一个需要同时选配音角色的职位。

## 在编辑工作区里录入 {#in-the-workspace}

作品工作区左侧的「制作人员」分区是一个两栏界面：中间一栏按职位分组列出本作的全部署名，右边一栏编辑选中的那一条。

- **添加署名**：点右上角「添加署名」，依次选职位、搜索署名名（可直接输入 ID），声优再选配音角色。找不到署名名时点「新建署名名」，会在新标签页打开新建页面，建好后回来再搜。
- **右栏上半部分「在本作中」**：编辑这条署名本身——职位、署名名、配音角色、备注、剧透、仅限发行、所属厂商。
- **右栏下半部分**：用「署名名 / 人物」开关切换，直接编辑这个署名名，或者它所属的人物。改动会和作品的改动一起提交，每个条目各生成一条修改记录。

## 资料源导入的署名 {#upstream-credits}

大部分署名来自 VNDB、Bangumi 等资料源。列表里每条都标着来源，人工添加的标「人工」。

资料源的署名**不能直接修改或删除**，因为导入任务每次同步都会把它写回来。你能做的有两件事：

### 隐藏 {#hide}

署名确实不属于这部作品（录错了作品、名字对错了人、重复的错误记录）时，点「隐藏」。隐藏后它不再出现在任何页面上，以后同步也不会再显示；随时可以「恢复显示」。

### 隐藏并添加修正记录 {#hide-and-correct}

署名的**大方向对、但有一项错了**——比如职位写错了、名字对到了错的署名名、声优配的角色不对——点「隐藏并添加修正记录」：系统会隐藏原来那条，同时复制一条一模一样的人工记录，并自动选中它让你修改。

> [!IMPORTANT]
> 复制出来的记录**必须至少改掉职位、署名名、配音角色中的一项**再提交。三项都和资料源那条相同的人工署名会被系统拒绝，提示「已由资料源提供，请用隐藏」。这是因为两条记录无法同时存在于同一个位置。

如果资料源那条只是备注、剧透等级或发行范围不准确，而职位、名字、角色都对，就不需要修正——保留它即可；确有必要时在修改说明里写清楚，交给审核者判断。

## 声优与角色 {#voice-actors}

声优署名把三样东西连在一起：作品、声优的署名名、角色。

- 声优的署名名照职员表或配音表上的原文录入，**包括成人作品里使用的另一个名义**（这种名义通常应作为独立马甲，归属可见性设为隐藏，见[归属可见性](/guidelines/credit-names-and-persons#link-visibility)）。
- 配音角色要选**本作里的那个角色条目**。角色还不在本作的角色列表里时，先到「角色」分区把角色加进来。
- 在「角色」分区选中一个角色时，右栏的「配音」会列出本作中为这个角色配音的声优，点一下就能跳到对应的署名。
- 一个角色由两位声优分别配音（例如不同版本换了声优），就是两条署名；如果只适用于某个版本，填「仅限发行」。

## 常见错误 {#common-mistakes}

| ❌ 错误做法                                    | ✅ 正确做法                                  | 原因                                       |
| ---------------------------------------------- | -------------------------------------------- | ------------------------------------------ |
| 署名名选了同名但不相干的另一个人               | 搜索时核对归属人物和代表作，必要时新建署名名 | 同名不等于同一人，选错会把作品记到别人名下 |
| 把「某某工作室」作为署名名录进来代替个人       | 录个人的署名名，公司填「所属厂商」           | 署名记录的是人的署名                       |
| 一个人兼任多个职位，只录一条并在备注写「兼任」 | 每个职位一条署名                             | 按职位检索时才找得到                       |
| 声优署名不选配音角色                           | 选上本作中的角色条目                         | 否则角色页上看不到声优                     |
| 资料源署名职位错了，删不掉就新增一条一模一样的 | 用「隐藏并添加修正记录」，并改正职位         | 完全相同的人工署名会被拒绝                 |
| 隐藏一条只是备注不完美的资料源署名             | 保留它                                       | 隐藏会让一条基本正确的记录消失             |
| 把罗马字写进署名名名称里来区分同名的人         | 新建独立的署名名，并在备注里写明区分依据     | 名称要与职员表原文一致                     |
