## 先看一个故事 {#a-story}

假设有一位原画师，现实中是同一个人：

- 在商业作品《夏日之岛》的职员表里，她署名为「**ゆずはら**」；
- 两年后在另一部商业作品里，她改用了「**柚原ことり**」这个名字；
- 她还以「**ことりっち**」的名义出同人本，并且不希望别人把这个同人名义和她的商业名字联系起来。

另一边，还有一位**完全不相干的**剧本作家，也叫「ゆずはら」。

在资料库里，这些信息应该这样记录：

| 条目 | 类型 | 说明 |
|---|---|---|
| ゆずはら（原画） | 署名名 | 归属人物 A，类型「笔名」 |
| 柚原ことり | 署名名 | 归属人物 A，类型「主名」 |
| ことりっち | 署名名 | 归属人物 A，类型「独立马甲」，归属可见性「隐藏」 |
| ゆずはら（剧本） | 署名名 | 归属人物 B——**和上面的「ゆずはら」是两条不同的署名名** |
| 人物 A | 人物 | 主署名「柚原ことり」 |
| 人物 B | 人物 | 主署名「ゆずはら」 |

记住这张表，下面的规则都是从它推出来的。

## 署名名是什么 {#what-is-a-credit-name}

**署名名**是作品职员表、配音表上**实际印出来的那个名字**。它是制作人员记录的直接对象：一条制作人员记录说的是「某部作品的某个职位，署名为某某」，而不是「某个人参与了某部作品」。

为什么要这样绕一层：

- 职员表上写的就是名字，录入时你看得到名字，却未必知道背后是谁。先把名字录对，归属哪个人可以以后再确认。
- 同一个人在不同作品里用不同名字，是很常见的事。按名字记录，才能如实反映「这部作品里她署的是哪个名字」。
- 同名的不同人也很常见。如果直接把记录挂在「人」身上，同名的人就会被错误地混在一起。

一条署名名包含：

| 字段 | 填什么 |
|---|---|
| 名称 | 职员表上的原文，一个字都不要改：保留原文的汉字、假名、空格与符号 |
| 罗马字 | 名称的罗马字写法（可选）。有官方罗马字就用官方写法 |
| 语言 | 这个名字本身的语言（通常是日语） |
| 类型 | 主名 / 笔名 / 独立马甲 / 曾用名，见下文 |
| 归属可见性 | 公开 / 隐藏：是否公开显示「这个名字属于哪个人物」，见下文 |
| 备注 | 给其他编辑者看的说明，例如「与同名剧本作家不是同一人，见某某访谈」 |
| 归属人物 | 这个名字属于哪个人物；不确定就留空 |
| 别名 | 同一个名字的其他写法或译名，见下文 |

> [!WARNING]
> 「名称」里只放职员表上的原文。罗马字写在「罗马字」，中文译名写在「别名」。不要写成「柚原ことり (Yuzuhara Kotori)」这种合并写法。

## 人物是什么 {#what-is-a-person}

**人物**是署名名背后的那个真实的人。一个人物可以有多个署名名；一个署名名最多属于一个人物。

人物条目本身记录的是「人」的信息：

| 字段 | 填什么 |
|---|---|
| 主署名 | 这个人最常用、最具代表性的署名名。人物在各处显示的名字就是它的名称；只能从这个人物自己的署名名里选 |
| 性别 | 已公开的信息才填 |
| 出生年 / 月 / 日 | 已公开的信息才填，可以只填一部分（例如只知道生日不知道年份） |
| 照片 | 官方公开的照片或头像；没有就不填 |
| 简介 | 每种语言一段，介绍这个人的经历与代表作 |
| 外链 | 个人网站、社交账号，以及 VNDB、Bangumi、批评空间上的人物页 |

> [!NOTE]
> 人物的「显示名」不能直接改：它永远等于主署名的名称。想改人物显示的名字，要么改主署名本身的名称（例如修正错字），要么把主署名换成这个人物的另一个署名名。

## 署名名的类型 {#credit-name-kinds}

| 类型 | 什么时候用 | 例子 |
|---|---|---|
| 主名 | 这个人最主要、最常用的名字。不一定是法律上的本名 | 柚原ことり |
| 笔名 | 和主名并用、公开承认是同一个人的其他名字 | ゆずはら |
| 独立马甲 | 本人刻意和其他名字分开经营的名义，例如参与成人作品时用的另一个名字 | ことりっち |
| 曾用名 | 这个人以前用过、现在已经不再使用的名字 | 改名前的旧名字 |

一个人物通常只有一个主名。拿不准时，「笔名」是最安全的选择——它只表示「这也是这个人用过的名字」。

## 归属可见性 {#link-visibility}

「归属可见性」控制的是**这个署名名和它所属人物之间的关系是否公开显示**，和网址链接无关。

- **公开**（默认）：在作品的制作人员表、人物页上都会显示「这个名字属于某某」。
- **隐藏**：资料库内部仍然知道这个名字属于谁，但公开页面不展示这层关系。用于本人明确把不同名义分开、或者业内默认不公开的情况（典型的是声优在成人作品中使用的名义）。

> [!IMPORTANT]
> 不要因为「我知道这是同一个人」就把隐藏改成公开。把本人刻意区分的名义公开关联，可能违背当事人的意愿。只有在当事人自己公开承认之后，才改为公开。

## 别名：同一个名字的其他写法 {#aliases}

署名名的**别名**用来记录「同一个名字」的其他写法，主要是为了让人搜得到：

- **译名**：这个名字的中文或其他语言写法，例如「柚原小鸟」；
- **异写**：同一名字的不同写法，例如全角／半角、旧字体／新字体、中间是否有空格。

每条别名填写名称、语言、类型，可选填罗马字；「该语言主名」表示这条别名是该语言下首选显示的写法。

**什么时候建别名，什么时候建新的署名名？**

| 情况 | 做法 | 原因 |
|---|---|---|
| 职员表上印的是「柚原 ことり」（多了一个空格） | 给「柚原ことり」加一条异写别名 | 是同一个名字的不同排版 |
| 想让人搜「柚原小鸟」也能找到 | 加一条中文译名别名 | 只是翻译，不是她用过的名字 |
| 她在另一部作品里署名「ゆずはら」 | **新建一条署名名**，归属同一个人物 | 这是一个不同的名字，有自己的作品记录 |
| 她改名了 | 新建署名名，旧名字类型改为「曾用名」 | 旧作品的职员表仍然印着旧名字 |

## 把署名名归属到人物 {#assign-to-person}

在署名名的「归属人物」里选一个人物，就把这个名字连同它的**全部制作人员记录**一起挂到了这个人物下。换到另一个人物、或者清空（表示暂未确认），也是同样的道理：制作人员记录始终指向署名名，名字走到哪里，记录就跟到哪里。

几条硬规则：

- **人物的最后一个署名名不能移走。** 一个人物至少要有一个名字。如果你发现某个人物其实和另一个人物是同一个人，正确做法是**发起人物合并**（见[新建条目与合并重复条目](/guidelines/create-and-merge)），而不是把它唯一的名字搬走、留下一个空壳。
- **移走主署名时**，系统会自动在这个人物剩下的署名名里选出作品记录最多的一个作为新的主署名。
- **新建人物只能从一个还没有归属的署名名开始。** 在编辑台「新建 → 人物」时要选一个尚未归属任何人物的署名名，新人物以它为主署名。
- 归属是共享数据的修改：署名名和人物都属于多部作品共用的条目，**所有人的修改（包括审核者自己的修改）都要经过另一位审核者确认**才会生效。

> [!CAUTION]
> 判断「是不是同一个人」要有依据：官方简介、本人社交账号、可靠的访谈或资料站上有出处的记录。**同名不等于同一个人。** 把两个同名的人归到同一个人物下，会让两个人的作品履历混在一起，而且很难被发现。

## 人物的身份链接 {#identity-links}

人物外链里，VNDB 的人物页（`vndb.org/s123`）、Bangumi 的人物页（`bgm.tv/person/123`）和批评空间的创作者页（`creater.php?creater=123`）属于**身份链接**：它们说明「这个人物就是那个资料站上的那个人」，导入任务会据此把资料站上的新作品记录对到这个人物身上。

- 你手动添加的身份链接会被记为「待确认」的身份链接，供导入任务和审核者参考；
- 其他网址（个人网站、推特、pixiv 等）是普通的相关链接；
- 资料源导入的**身份链接不能隐藏**。如果它指错了人，说明是「名字归错了人」，要通过**把署名名移到正确的人物**（必要时先新建人物）来纠正，而不是隐藏链接；
- 资料源导入的普通相关链接可以隐藏。

> [!TIP]
> 填外链时直接粘贴完整网址即可，系统会自动识别是哪个资料站的人物页。把作品页的网址填进人物外链会被拒绝。

## 一步步：修正一个归错的人 {#walkthrough-split}

场景：人物「ゆずはら」下面挂了两个名字，其中「ゆずはら（剧本）」其实是另一个人。

1. 打开那条剧本作家的署名名，在「归属人物」里**清空**（因为人物 A 还有其他名字，所以允许移走）。
2. 在编辑台「新建 → 人物」，选择这条刚刚变成未归属的署名名，新建人物 B。
3. 在修改说明里写清依据，例如「剧本作家ゆずはら与原画师ゆずはら为不同人，见某某官网职员介绍」。
4. 如果原来的人物 A 上挂着属于 B 的身份链接（例如 VNDB 人物页），在审核时说明，由审核者处理。

## 常见错误 {#common-mistakes}

| ❌ 错误做法 | ✅ 正确做法 | 原因 |
|---|---|---|
| 把同名的两个人合并成一个人物 | 两个人物各自保留，名字分别归属 | 同名不等于同一人，合并后履历混在一起 |
| 每看到一种写法就新建一个人物 | 一个人一个人物，写法差异用别名或新的署名名 | 人物数应该等于真实的人数 |
| 名称里写「柚原ことり (Yuzuhara Kotori)」 | 名称写原文，罗马字填「罗马字」 | 名称要与职员表原文一致，罗马字有专门字段 |
| 把中文译名填进「名称」 | 中文译名加为「译名」别名 | 名称只放职员表上的原文 |
| 制作人员写成公司名（「某某工作室」）来代替个人 | 录个人的署名名；公司放在「所属厂商」 | 署名名记录的是人的署名 |
| 为了让隐藏马甲出现在人物页上，把归属可见性改为公开 | 只有本人公开承认后才改 | 尊重当事人刻意的区分 |
| 把人物唯一的名字移到别的人物下 | 发起人物合并 | 人物不能没有名字 |
| 隐藏导入的身份链接来「解除」错认 | 把署名名移到正确的人物 | 身份链接不能隐藏，错认要从归属上纠正 |
