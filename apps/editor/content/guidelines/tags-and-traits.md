## 词表条目 vs. 给作品或角色打标签 {#vocabulary-vs-usage}

| 你想做的事 | 去哪里 |
|---|---|
| 给某部作品加一个标签、调整它的剧透等级 | 作品工作区「标签」分区，见[标签与剧透](/guidelines/tags-and-spoilers) |
| 给某个角色加一个特质 | 角色的「特质」标签页，见[角色](/guidelines/characters#traits) |
| 修正「白发」这个特质本身的中文名、说明、所属分组 | 特质自己的编辑页（本篇） |
| 修正「岛」这个标签本身的名称、说明、上级标签 | 标签自己的编辑页（本篇） |

词表条目被成千上万部作品和角色共同使用，改动影响面很大，所以**所有人的修改都要经过另一位审核者确认**，而且有几项只有审核者能改（见下文）。

## 标签 {#tags}

### 名称与说明 {#tag-name}

- **名称**：标签的正式名称。名称在整个词表里必须唯一——不能把一个标签改成和另一个标签同名；如果两个标签其实是一个意思，请联系审核者合并，而不是改名撞名。
- **说明**（简介）：每种语言一段，写清这个标签**什么情况下该用、什么情况下不该用**，最好附一个正例和一个反例。说明写得清楚，标签才不会被乱用。
- **备注**：给其他编辑者看的内部说明，例如「与某某标签的区别」。

### 类型 {#tag-kind}

| 类型 | 用于 |
|---|---|
| 内容 | 描述作品内容：题材、设定、剧情要素、角色属性 |
| 元信息 | 描述作品本身的形式与制作信息：多结局、有配音、地图移动等 |

### 层级与色情相关（仅审核者） {#tag-tier-and-sexual}

| 字段 | 取值 | 作用 |
|---|---|---|
| 层级 | 核心 / 长尾 / 隐藏 | 「隐藏」的标签不出现在默认的标签列表里；核心与长尾区分常用词和冷门词 |
| 色情相关 | 是 / 否 | 标为色情相关的标签，在全年龄（SFW）页面和默认列表里不展示 |

> [!IMPORTANT]
> 这两项决定了**各个站点的默认列表隐藏哪些内容、全年龄页面不展示哪些内容**，改错会让露骨内容出现在全年龄页面，或让正常标签消失。所以只有审核者可以提交这两项的修改。觉得某个标签的分类不对，在修改说明或讨论区里告诉审核者。

### 上级标签 {#tag-parents}

上级标签组成标签的层级树，例如「白毛女主角」的上级可以是「女主角发色」。规则：

- 一个标签最多 20 个上级；
- 不能把标签设为自己的上级，也不能形成循环（A 的上级是 B，B 的上级又是 A）——这样的修改会被拒绝；
- 资料源（VNDB）同步来的上级关系可以单独隐藏；人工把同一条关系再添加一次，表示「确认这条关系」，以后的同步不会再删掉它；
- 同一条关系不能既被隐藏又被人工添加：要重新启用已隐藏的关系，先在一次单独的修改里取消隐藏。

### 新建标签（仅审核者） {#tag-create}

新建标签只有审核者可以提交。普通编辑者需要新标签时，在讨论区或修改说明里提出，附上标签的定义和适用的作品例子。系统会检查是否已有同名（忽略大小写和全半角差异）的标签。

## 特质 {#traits}

特质描述角色：外貌、服饰、性格、身份、经历、关系等。特质词表主要来自 VNDB，所以很多特质的「名称」是英文。

### 名称与中文名 {#trait-name}

| 字段 | 填什么 |
|---|---|
| 名称 | 特质的原始名称（多为 VNDB 的英文名），一般不需要改 |
| 中文名 | 编辑台和各站点显示用的中文名。很多中文名是机器翻译的，可以直接改写 |
| 别名 | 这个特质的其他叫法，每条一个 |
| 说明 / 中文说明 | 特质的定义。中文说明同样可能是机器翻译，可以改写 |

> [!TIP]
> 中文名和中文说明一旦由人工改写，机器翻译任务就**不会再覆盖**它们。改写时注意术语和同组其他特质保持一致（例如「发色」组里统一用「X发」）。

### 分组 {#trait-groups}

特质按「分组」组织，例如「头发」「性格」「身份」。**分组本身也是一个特质**——它是顶层的、没有自己分组的特质。

- 「所属分组」只能指向一个分组（顶层特质）；不能指向一个本身属于别的分组的特质，也不能指向自己；
- 一个已经是其他特质的分组的特质，不能再加入别的分组；
- 「分组内排序」决定特质在分组里的显示顺序。

### 标注相关的设置 {#trait-flags}

| 字段 | 作用 |
|---|---|
| 可直接标注 | 是否可以把这个特质加到角色上。分组标题（如「发色」）应为「否」，具体特质（如「白发」）为「是」 |
| 可用于搜索 | 是否出现在按特质搜索角色的筛选里 |
| 默认剧透等级 | 给角色添加这个特质时默认的剧透等级。例如「已死亡」这类特质默认应为严重剧透 |
| 色情相关（仅审核者） | 和标签的同名设置作用相同：标为色情相关的特质在全年龄页面不展示 |

### 上级特质 {#trait-parents}

与上级标签规则相同：不能循环、不能以自己为上级，资料源同步的关系可以隐藏或人工确认。

### 新建特质（仅审核者） {#trait-create}

新建特质只有审核者可以提交；同一个分组里不能有两个同名的特质。

## 常见错误 {#common-mistakes}

| ❌ 错误做法 | ✅ 正确做法 | 原因 |
|---|---|---|
| 为了修正某部作品的标签，去改了标签本身的名称 | 在作品的标签分区里换标签或调整剧透 | 改词表会影响所有使用它的作品 |
| 两个标签意思相同，把其中一个改名成另一个的名字 | 请审核者合并 | 名称必须唯一，撞名会被拒绝 |
| 把「发色」这样的分组标题设为可直接标注 | 分组标题设为不可直接标注 | 角色应该标具体特质 |
| 把机器翻译的中文名原样保留，同组特质译法各不相同 | 改写中文名，统一同组译法 | 人工改写后不会再被机翻覆盖 |
| 说明里只写一个词 | 写清适用范围和正反例 | 说明是别人判断「该不该打这个标签」的依据 |
| 普通编辑者尝试修改层级或色情相关 | 告诉审核者 | 这两项只有审核者能提交 |
