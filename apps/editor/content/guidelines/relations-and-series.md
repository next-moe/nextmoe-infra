「关联作品」记录这部作品和**另一部作品**之间的关系；「系列」把多部作品归入同一个系列，并记录每部作品在系列中的位置。两者经常同时出现（同一系列的作品之间通常也有续作关系），但用途不同：

- **关联作品**回答「A 和 B 是什么关系」；
- **系列**回答「这个系列有哪些作品、按什么顺序」。

## 关系类型 {#relation-types}

编辑台总是**从本作出发**描述关系。选择关系时，你选的是一句话，例如「本作 **是…的续作** 对方」或「本作 **有续作** 对方」。

| 关系 | 从本作出发 | 反过来 | 用于 |
|---|---|---|---|
| 续作 | 是…的续作 | 有续作 | 剧情直接承接的正统续篇 |
| 外传 | 是…的外传 | 有外传 | 同一世界观下、主线之外的故事 |
| Fandisc | 是…的 Fandisc | 有 Fandisc | 以原作角色为主的追加内容作品（FD） |
| 重制 | 重制自 | 被重制为 | 重新制作的版本（画面、剧本、系统大幅更新） |
| 改编 | 改编自 | 被改编为 | 跨媒介改编：游戏改动画、小说改游戏等 |
| 收录 | 收录 | 被收录于 | 合集、完全版收录了单独发售的作品 |

以下关系**不分方向**（对称关系），两部作品互为对方的同一种关系：

| 关系 | 用于 |
|---|---|
| 同系列 | 属于同一系列，但没有直接的续作 / 外传关系 |
| 同世界观 | 共享世界观设定，但不是同一系列 |
| 联动 | 两部作品之间的官方联动 |
| 角色出演 | 一部作品的角色在另一部中客串登场 |
| 不同世界观 | 同一批角色出现在完全不同的设定中（如学园 IF） |
| 不同演绎 | 同一作品的另一种版本 / 演绎方式 |

> [!WARNING]
> **方向很容易选反。** 选之前把句子念一遍：「本作 是 对方 的续作」——如果本作是先出的那部，就应该选「本作 **有续作** 对方」。

| | 本作 | 对方 | 应选 |
|---|---|---|---|
| ✅ | 《二代》 | 《一代》 | 是…的续作 |
| ✅ | 《一代》 | 《二代》 | 有续作 |
| ✅ | 动画版 | 游戏原作 | 改编自 |
| ❌ | 《一代》 | 《二代》 | 是…的续作（方向反了） |

### 版本、重制、FD、外传怎么分 {#versions-vs-remakes}

- **同一部作品的不同发行**（移植版、追加版、汉化版、廉价版、下载版）**不是关联作品**，它们是这部作品的 [发行](/guidelines/releases)。只有被当作独立作品记录、而且确实是另一部作品时，才用关联作品。
- **重制**：重新制作，与原版内容有大幅差异，通常作为独立作品发售。
- **Fandisc**：以原作角色的后日谈、追加剧情为主，一般需要原作知识。
- **外传**：同一世界观的另一个故事，主角或时间线不同。
- **完全版 / 合集**：收录了已有作品的，用「收录」。

> [!NOTE]
> 如果发现「关联作品」里有一部其实就是**同一部作品**（重复条目），不要用「不同演绎」把它们连起来——请发起 [合并请求](/guidelines/create-and-merge)。

### 规则与限制 {#relation-rules}

- 一部作品不能和自己建立关系；同一对作品、同一种关系、同一方向只能有一条。
- 关系写在两部作品之间，**两边的页面都会显示**。
- 资料源导入的关系不能直接修改：认为它不对时，**隐藏**它（两部作品上都会消失），再添加一条正确的。
- 一条关系被隐藏后，不能在同一次修改里再人工添加同样的关系；需要先单独提交一次取消隐藏。
- 备注最多 300 字，用于补充说明（例如「仅指 PC 版」），不要写评价。
- 对方作品的资料要在它自己的编辑页修改；修改关系不会改动对方作品的其他信息。

## 系列 {#series}

系列分为两类：

- **资料源生成的系列**：由导入流程根据资料源自动维护，**不能在这里加入或退出**，但可以隐藏某个导入的系列归属；
- **人工维护的系列**：由编辑者建立和维护，可以把作品加入或移出。

> [!IMPORTANT]
> 「加入系列」只能选择**人工维护的系列**。找不到合适的人工系列时，可以先 [新建一个系列](/new/series)（需要符合 [新建条目](/guidelines/create-and-merge) 的规则），再把作品加进去。

### 在系列中的位置 {#series-position}

每部作品在每个所属系列中有两项设置：

| 项目 | 含义 | 填法 |
|---|---|---|
| **序号** | 在系列中的排序 | 一般按发售顺序，从 1 开始；同一系列中避免重复；0 表示尚未确定 |
| **身份** | 在系列中的角色 | 正篇 / Fandisc / 外传 / 合集 / 未分类 |

系统会按各作品最早的发售日期，自动给资料源生成的系列编号（没有发售日期的排在最后）。自动编号不对时可以手动调整；人工改过的序号和身份，之后的自动编号和资料源同步都不会覆盖。

新加入系列的作品，要等加入的修改生效之后才能设置序号和身份。

## 常见错误 {#common-mistakes}

- **关系方向选反**：先念一遍「本作 是 对方 的……」。
- **把移植版、汉化版当成关联作品**：它们是发行，不是另一部作品。
- **用关联作品连接重复条目**：重复条目请合并。
- **试图修改导入的关系**：先隐藏，再添加正确的。
- **想把作品加入资料源生成的系列**：只能加入人工维护的系列。
- **系列序号乱填**：按发售顺序编号，保持连续。

## 字段对照 {#field-reference}

| 界面名称 | 字段 | 说明 |
|---|---|---|
| 关联作品 | `catalog.work.relations` | 对方作品 / 关系 / 反向 / 备注 |
| 已隐藏的关联 | `catalog.work.relations.suppressed` | 隐藏后两部作品上都不显示 |
| 所属系列 | `catalog.work.series_ids` | 只能是人工维护的系列 |
| 已隐藏的系列归属 | `catalog.work.series_ids.suppressed` | 资料源生成的系列归属 |
| 系列内位置 | `catalog.work.series_members` | 系列 / 序号（0–9999）/ 身份 |
