「媒体」分为**封面**和**截图**两个分区。两者的界面相同：一个合并了人工上传与资料源导入图片的网格，点击任意一张，右侧检视栏可以查看大图并修改它的属性。

## 封面与截图的区别 {#covers-vs-screenshots}

|      | 封面                             | 截图               |
| ---- | -------------------------------- | ------------------ |
| 内容 | 官方的主视觉、包装图、数字版封面 | 游戏内的实际画面   |
| 用途 | 作品卡片、页面头图               | 作品页的截图区     |
| 属性 | 类型、主封面、性暗示、暴力       | 说明、性暗示、暴力 |

宣传 CG、角色立绘拼图如果是官方主视觉，可以作为封面；游戏画面（含对话框、UI 的截图）请放进截图。

## 封面类型 {#cover-kinds}

| 类型                                       | 含义                           |
| ------------------------------------------ | ------------------------------ |
| **主视觉**                                 | 官方主宣传图（Key Visual）     |
| **包装正面**                               | 实体包装的正面照片或扫描       |
| **包装背面** / **包装侧面** / **包装内容** | 包装的其他面、附带的册子与特典 |
| **光盘介质**                               | 光盘盘面                       |
| **数字版封面**                             | 数字发行（下载版）使用的封面   |
| **未分类**                                 | 不确定时使用                   |

> [!NOTE]
> **包装类图片（包装正面 / 背面 / 侧面 / 内容 / 光盘介质）不会被选作作品卡片和头图**，它们只在作品的图片列表里展示。作品卡片和头图从主视觉、数字版封面、未分类的图片里选出。所以类型要标准确：把一张主视觉标成「包装正面」，它就不会出现在作品卡片上。

## 主封面与页面上的封面 {#main-cover}

作品卡片上的竖版封面（以及页面头图）是系统按规则自动选出的：

1. 被设为**主封面**的那张优先——前提是它是竖版图（如果系统已知它的尺寸且它是横版，会被跳过）；
2. 否则选清晰度最高的竖版图（宽度 500 像素以上优先）；
3. 横版头图选清晰度最高的横版图（宽度 800 像素以上优先），没有横版封面时会用截图代替；
4. 从其他作品合并过来的图片，排在这部作品自己的图片之后；多部作品共用的同一张图（如合集包装），排在作品专属的图片之后。

**主封面只能有一张**。在检视栏里点「设为主封面」，原来的主封面会自动取消。

> [!TIP]
> 只有当系统自动选出的封面不合适时（比如选到了一张清晰但不具代表性的图），才需要手动指定主封面。

## 分级：性暗示与暴力 {#grading}

**每一张**封面和截图都要标两项分级。它们决定图片在全年龄（SFW）页面上能不能出现：

**性暗示**

| 等级     | 判断标准                                                     |
| -------- | ------------------------------------------------------------ |
| **安全** | 没有性暗示：正常着装、日常场景                               |
| **擦边** | 有性感元素但不露骨：泳装、内衣、强调身材的构图、暗示性的姿势 |
| **露骨** | 露出性器官或乳头、性行为、明显的性内容——包括打了码的同类画面 |

**暴力**

| 等级     | 判断标准                   |
| -------- | -------------------------- |
| **无**   | 没有暴力内容               |
| **暴力** | 打斗、受伤、轻度出血       |
| **血腥** | 强烈的血腥、肢解、残酷画面 |

> [!IMPORTANT]
> **宁高勿低。** 标为「露骨」的图片不会出现在全年龄页面上；标低了，露骨的图就会直接展示给所有读者。打了马赛克或光效遮挡的露骨画面，仍然是「露骨」。

> [!WARNING]
> 一部作品如果**所有可选作封面的图都是露骨**，整部作品会被强制按 NSFW 方式展示（见 [按 NSFW 内容显示](/guidelines/work-basics#display-nsfw)）。如果作品其实有安全的封面，请检查是不是把安全的图误标成了露骨，或者安全的主视觉被误标成了包装类图片。

资料源导入的图片同样可以改分级、改类型、设为主封面；改过的值会保留，资料源再同步不会覆盖。

## 排序 {#ordering}

网格里的图片可以**整体拖动排序**，人工上传的和资料源导入的可以混排；键盘上用 Alt + 方向键也能移动选中的图片。排好的顺序就是作品页上的展示顺序。

- 没有手动排过序时，使用系统的默认顺序；
- 「恢复默认顺序」会清除手动顺序；
- 之后新导入的图片排在手动排好的图片之后。

## 上传 {#upload}

- 点「上传封面 / 上传截图」，或直接把图片文件**拖进网格**，可以一次上传多张。
- 支持 PNG、JPEG、WebP、AVIF、GIF，单张最大 20 MB。
- 上传后记得在检视栏里补上类型（封面）或说明（截图）和分级。

**只上传有权使用的官方图片**：官方宣传素材、官方商店页图片、自己截取的游戏画面。

|     | 图片                            | 说明           |
| --- | ------------------------------- | -------------- |
| ✅  | 官网下载的主视觉原图            | 可以           |
| ✅  | 自己游玩时截取的原始画面        | 可以，作为截图 |
| ❌  | 带有其他网站水印的图            | 请找原图       |
| ❌  | 同人图、玩家自制拼图、AI 生成图 | 不允许         |
| ❌  | 被拉伸、加边框、随意裁剪过的图  | 请用原始比例   |
| ❌  | 其他作品的图、与作品无关的图    | 不允许         |

资料源已经收录的同一张图不能再上传一次——直接修改它的属性即可。

## 隐藏与删除 {#hide-and-delete}

| 操作     | 适用于           | 效果                                                     |
| -------- | ---------------- | -------------------------------------------------------- |
| **删除** | 人工上传的图片   | 从作品上移除；提交前可以「撤销删除」                     |
| **隐藏** | 资料源导入的图片 | 不再在任何页面显示，资料源再同步也不会恢复；可以随时恢复 |

适合隐藏的情况：图片与作品无关、重复的低清版本、损坏的图片、不是这部作品的封面。仅仅因为图片露骨**不是**隐藏的理由——请把分级标对。

## 常见错误 {#common-mistakes}

- **分级标低**：打码的露骨画面仍是露骨；拿不准时往高标。
- **把主视觉标成包装类型**：包装类图片不会出现在作品卡片上。
- **因为露骨而隐藏图片**：应当标「露骨」，系统会自动对全年龄读者隐藏。
- **上传带水印或二次加工的图**：请使用官方原图。
- **把游戏画面当封面、把封面当截图**：两者用途不同。
- **主封面选了横版图**：作品卡片是竖版的，横版图不会被采用。

## 字段对照 {#field-reference}

| 界面名称         | 字段                                  | 说明                                 |

| 截图顺序         | `catalog.work.screenshot_order`       | 图片顺序；清空即恢复默认             |
