未萌编辑台（editor.nextmoe.com）是 NextMoe 资料库唯一的编辑入口。论坛、moyu、LetMoe 等站点上的「编辑资料」按钮都会把你带到这里，用的是同一个账号——只要在其中任一站点登录过，进入编辑台时会自动登录，不需要再输入密码。

## 两个界面 {#two-shells}

| 界面       | 地址                  | 用途                                                             |
| ---------- | --------------------- | ---------------------------------------------------------------- |
| 编辑台     | [/](/) 及各列表页     | 浏览与搜索条目、查看你的提案和贡献、审核队列、修订历史、编辑规范 |
| 编辑工作区 | `/<类型>/<编号>/edit` | 专心编辑**一个条目**及与它关联的条目                             |

编辑台里所有「编辑资料」按钮都会在**新标签页**打开工作区；从下游站点点「编辑」也会直接进入工作区。

## 编辑工作区的布局 {#workspace-layout}

- **顶栏**：条目名称与编号；「查看更改」（显示未提交修改的数量）；「提交」；「⋯」菜单（查看资料页、修订历史、放弃全部修改）；如果你是从下游站点过来的，还有「返回 论坛 / moyu / LetMoe」。
- **左栏**：只列这个条目的分区。作品是：基础、标题、简介、标签、外链、封面、截图、角色、制作人员、厂商、引擎与平台、系列、关联作品、发行。每个分区右侧显示条目数；有未提交的修改时显示蓝色的修改数。最上面「返回工作台」，最下面是本规范。左栏可以折叠成图标栏。
- **内容区**：当前分区的编辑界面。当前分区和选中项会写进地址栏（`?section=roster&item=7937`），刷新或分享链接都会回到同一个位置。

### 列表字段：一张表看全部 {#merged-lists}

标题、标签、外链、厂商、制作人员等列表里，资料源导入的行和人工添加的行显示在一起，每行标出来源。人工行可以直接修改和删除，资料源行可以隐藏和恢复。新增、修改、删除、隐藏的行左侧有不同颜色的标记。为什么资料源行只能隐藏，见[资料源数据与人工编辑](/guidelines/upstream-data)。

### 关联条目：就地编辑 {#related-panes}

角色、制作人员、厂商、引擎、系列、关联作品、发行这几个分区是「列表 + 详情」两栏：

- 左边列出这部作品下所有该类条目，可以筛选；
- 选中一项，右边上半部分编辑它**在这部作品中的设定**（例如角色的出场程度、署名的职位、厂商的身份），下半部分直接编辑**这个条目本身**（例如角色的资料、简介、特质），分成几个标签页；
- 宽屏下默认选中第一项；手机上先看列表，点进去再编辑，左上角「返回」回到列表。

在这里改的角色、人物、厂商，和作品的修改一起暂存，切换来切换去都不会丢。想单独处理某个关联条目，点详情右上角的外链图标，会在新标签页打开它自己的工作区。

## 第一次修改：完整走一遍 {#first-edit}

以给一部作品补充中文简介为例：

1. 在论坛的作品页点「编辑资料」，编辑台在新标签页打开这部作品。
2. 左栏点「简介」。顶部的语言标签显示哪些语言已有简介、哪些缺失；点标着「缺失」的虚线框「简体中文」开始写。
3. 写完后，字段左侧出现蓝色竖线，左栏「简介」旁显示修改数，顶栏「查看更改」亮起。
4. 点「查看更改」核对：每一处修改都有前后对比，不想要的可以单独撤销。
5. 点「提交」（Ctrl / ⌘ + S），写明简介来源（例如「据官网故事介绍改写」），确认。
6. 对话框告诉你修改是「已生效」还是「待审核」，并给出提案链接。待审核的提案在 [/me/proposals](/me/proposals) 查看进度，被处理后顶栏通知会提示你。
7. 点「返回 论坛」回到原来的页面。

> [!TIP]
> 提交前一定要看一眼「查看更改」。很多被退回的提案，是不小心改动了不想改的字段。

## 草稿 {#drafts}

你的修改会实时保存在本机浏览器里。不小心关掉页面，下次打开同一条目时会提示恢复草稿。草稿不会上传，也不会被别人看到；换设备就看不到了。所有本机草稿在 [/me/drafts](/me/drafts)。

| [/changes](/changes)                     | 全站最近的修订                                         |

| [/apply](/apply)                         | 申请成为编辑者                                         |

## 快捷键 {#shortcuts}

| 按键            | 作用                                     | 位置       |
| --------------- | ---------------------------------------- | ---------- |
| Ctrl / ⌘ + S    | 提交（有未完成的问题时打开「查看更改」） | 编辑工作区 |
| `j` / `k`       | 下一个 / 上一个字段                      | 审核工作台 |
| `a` / `e` / `r` | 采纳 / 修正 / 拒绝当前字段               | 审核工作台 |
| `m` / `d`       | 合并提案 / 拒绝整条提案                  | 审核工作台 |
| `]` / `[`       | 下一条 / 上一条提案                      | 审核工作台 |
| `?`             | 显示快捷键列表                           | 审核工作台 |

## 常见错误 {#common-mistakes}

| ❌ 做法                                        | ✅ 应该                                        |
| ---------------------------------------------- | ---------------------------------------------- |
| 不看「查看更改」就提交                         | 提交前逐项核对前后差异                         |
| 在几个标签页里同时编辑同一个条目               | 每个条目只在一个标签页里编辑，避免草稿互相覆盖 |
| 以为关掉页面修改就没了，于是在别的设备重做     | 草稿保存在原设备的浏览器里，回原设备恢复       |
| 在关联条目里改了角色资料，却只检查了作品的修改 | 「查看更改」会按条目列出全部修改，一起核对     |
